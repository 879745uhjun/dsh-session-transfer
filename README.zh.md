# 会话搬家 · dsh-session-transfer

把 DSH 里**任意一个会话**打包成一个 `.dshpack` 文件，拷到另一台电脑的 DSH 上导入后继续使用。

一个包会带上：

- 完整会话记录：对话、工具调用与结果、改动、审批、标题、模型与预设选择；
- 这个会话派生的**子会话**（subagent），默认包含；
- 记录里引用到的**图片**和**上传文件**（按内容寻址，原样恢复）。

导入时可以选择落到哪个工作区，会话路径、预设、会话 id 冲突都会被自动处理。

---

## 安装

插件需要**两台电脑都装**（打包端和导入端）。

### 方式一：在 DSH 界面里安装（推荐）

1. 把整个 `dsh-session-transfer` 文件夹拷到目标电脑，例如 `D:\dsh-plugins\dsh-session-transfer`；
2. 打开 DSH：**设置 → 插件 → 安装**，输入这个文件夹的**绝对路径**（或先在本机执行 `npm pack`，把生成的 `.tgz` 文件路径填进去）；
3. 重启 / 重新加载 DSH 窗口。

> 插件管理接受本地绝对路径、`file:` 路径和 `.tgz` 包；desktop 配置档由 DSH 应用自己管理，不需要手改 profile。

### 方式二：命令行（非 desktop 配置档）

```bash
dsh plugin --profile web add "D:\dsh-plugins\dsh-session-transfer"
```

### 验证

装好后：

- 侧边栏每个会话的「…」菜单里多出 **打包会话…**；
- 侧边栏底部多出 **导入会话包** 按钮；
- 对智能体说「把当前会话打包」时，能看到 `pack_session` / `unpack_session` 两个工具。

## 使用

### 打包（源电脑）

会话列表里把鼠标移到会话上 →「…」→ **打包会话…**。

- 宿主会读取会话日志、子会话和附件，压缩成一个 `.dshpack`；
- 底部进度卡片显示打包、下载进度，可取消；
- 浏览器按「会话标题.dshpack」保存到下载目录。

也可以让智能体代劳：

```
pack_session({ sessionId: "session-...", path: "D:\\临时\\会话.dshpack" })
```

`sessionId` 省略时就是当前会话；`path` 必须在 DSH 目录或已注册工作区内，省略时写到 `~/.dsh/session-packs/`。

### 整盒打包（1.1.0）

会话「…」→ **打包所在盒子…**（会话在多个盒子里会让你选一个）；智能体用 `pack_box`。整盒包是 `.dshpack` v2，除了会话和附件，还带盒子名称/颜色/顺序/折叠/表头、直接子盒和成员顺序。

导入整盒包时，预检会先给出盒子计划：

- 同名盒（name + parent 相同）默认**复用**，不改它已有的颜色/顺序/表头；
- 也可选「新建副本」，盒名加后缀「（导入）」；
- 盒子通过 boxes 插件的公开路由恢复，transfer 不直接写它的数据文件；
- boxes 不可达时，会话照常导入，结果标注“未归盒”；
- 归盒失败不回滚已导入的会话；置顶顺序不迁移会提示。

老版本（1.0.x）遇到 v2 包会明确报“版本不支持”，不会半导入。

### 导入（目标电脑）

1. 把 `.dshpack` 拷到目标电脑；
2. 侧边栏底部 → **导入会话包**；
3. 选择目标工作区和文件，DSH 会先**预检**并展示：会话标题、会话/事件/附件数量、要导入到哪个路径、来源 DSH 版本与格式，以及哪些 id 会变成副本、哪个预设会被替换；
4. 确认无误后点「确认导入」。成功后可以直接「打开会话」，或点「完成」后从侧边栏进入（会挂在工作区列表最前面）。

预检出错不会写入任何东西；重试会重新预检。Esc 关闭、Enter 确认，导入过程中不能关闭窗口。写入完成后宿主会立刻**读回校验**（事件数、头部、内容摘要），校验不过会明确报错而不是留下一个打不开的会话。

智能体导入：

```
unpack_session({ path: "D:\\下载\\会话.dshpack", workspace: "workplace" })
```

`workspace` 可以写工作区 id、绝对路径或唯一标题；省略时用第一个工作区。加 `dryRun: true` 只校验和预演，不写入。

## 导入时会发生什么

| 项目 | 处理方式 |
| --- | --- |
| 工作区路径 | 会话头里的 `cwd` 改写为你选择的工作区路径；历史记录里的旧路径只是文本，保持原样 |
| 会话 id | 本机已存在同 id 时，自动生成新 id 作为副本导入，并同步改写子会话的 `parentSession` 与日志内的自身 id 记录 |
| 预设 | 目标机没有原预设时，改用当前默认预设，并返回提示 |
| 图片/文件 | 按内容地址恢复到附件库；文件原样落盘，图片写回其规范化对象路径 |
| 标题 | 保留会话内的标题事件，不需要重新生成 |
| 完整性 | 导入后立即从存储读回并按摘要比对，失败会报告「写入会话失败」 |
| 挂载 | 根会话自动挂到目标工作区，出现在侧边栏 |

**不会**包含：工作区里的其它文件、星级、会话分组、定时任务等其它插件的数据。

## 包格式（`.dshpack`）

普通 ZIP，可以直接改名 `.zip` 用任何解压工具查看：

```
dsh-session-pack.json                 清单：来源版本、会话列表、附件列表、校验和
sessions/<session-id>.jsonl           规范化会话日志（首行会话头 + 逐条事件）
attachments/images/<sha256>.<ext>     规范化图片对象
attachments/files/<sha256>/<文件名>   原样文件对象
```

- 清单记录来源 DSH 版本与会话格式版本；导入前逐项校验 SHA-256、事件数与连续性；
- 入口名、大小、CRC 全部校验，防目录穿越、防损坏；
- 大小上限：会话包 2 GiB、单条目 1 GiB、条目数 65535。

## 兼容性

- 会话格式：**v4**（DSH `0.2.2-rc.1` 系列）。包内记录格式版本，格式不一致时导入会直接报错并提示版本，而不是静默损坏；
- 包布局：`packVersion 1`，未来更高版本会被旧插件拒绝；
- 插件引擎要求：`dsh >= 0.2.2-rc.1 < 0.3.0`。

## 隐私

包**未加密**，里面是完整对话（可能包含代码、路径、密钥片段、工具输出）。请像对待普通源码压缩包一样保管和传递；需要公开分享前请自行检查内容。

## 常见问题

**导入后侧边栏没看到会话？**
切到目标工作区，或刷新页面；导入接口返回的会话 id 可以用于 `unpack_session` 之外的人工核对。

**提示「会话格式不兼容」？**
两台电脑 DSH 的会话格式代际不同。升级/统一 DSH 版本后重试（插件不会尝试有损迁移）。

**提示「预设不存在」？**
已在导入时自动换成默认预设并给出警告；如需原预设，先在目标机安装对应预设插件再导入。

**打包/导入报错但不知道原因？**
- 打开 `http://127.0.0.1:<DSH 端口>/session-transfer/health` 看插件宿主是否在、版本与依赖服务是否齐全；
- 后台诊断日志在 `~/.dsh/tmp/session-transfer.log`（只记录失败，不记录会话内容）；
- 提示「会话不存在」通常是侧边栏里残留了已删除会话的行，刷新列表后重选即可。

**能只打包会话、不带附件吗？**
当前版本总是带上引用到的附件，以保证会话可读；会话很大时包也会相应变大。

## 卸载

在 DSH 插件管理里禁用或移除 `dsh-session-transfer`；已有 `.dshpack` 文件和已导入的会话不受影响。

## 开发

```bash
npm test        # ZIP / 包格式 / 导入导出的单元测试（node:test，无外部依赖）
```

代码结构：

- `lib/zip.mjs`：零依赖 ZIP 读写（UTF-8、store/deflate、CRC 校验、防穿越）；
- `lib/pack.mjs`：清单元数据、日志编解码、附件引用收集；
- `lib/transfer.mjs`：基于 `sessionPersistence` / `sessionQuery` / `attachments` / `workspaceRegistry` 服务的导入导出；
- `index.js`：宿主插件（HTTP 路由 + 两个智能体工具）；
- `client.js`：Web 端入口（会话菜单、底部导入按钮、导入对话框、打包进度卡片）。

开发复盘：

- [DSH 插件开发耗时分析与提速清单](docs/time-audit.zh.md)：一次真实插件开发会话的时间账、根因与提速清单；
- `docs/session-time-audit.mjs`：通用会话耗时审计脚本，可分析任意 DSH 会话的模型/工具/空闲耗时：

```bash
node docs/session-time-audit.mjs --session <会话 id>
```
